# Stitch HTML exports

1. Finish the design in **Stitch**.
2. Open **View code** and save the HTML here (`<page-name>.html` or `<page-name>/index.html`).
3. Ask the AI to convert it into React under `front/src/` — shared pieces go to `components/common/`.

This folder is the **design source**. The running app is React, not these HTML files.

Rules: `docs/03-front.md`, `docs/07-ai-md-workflow.md`, README **How to Dev?**

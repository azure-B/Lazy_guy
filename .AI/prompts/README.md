# One-file AI prompts

Absolute beginners: attach **one** of these files in chat (`@`), then type your wish in plain words.

| File | Who | Job |
|------|-----|-----|
| `A-mcp.md` | Everyone (once) | Connect MCP keys |
| `B-front.md` | Front | Stitch HTML → React |
| `C-back.md` | Back | New API |
| `D-db.md` | Back | ERD + Supabase SQL |
| `E-python.md` | Python | Scripts only |
| `F-fullstack.md` | Front + Back | Screen + API |
| `G-fix.md` | Everyone | **Errors — fix in one pass** |
| `H-preview.md` | Everyone | **Show result — run React + Node** |

The AI must open every path listed inside each prompt file.  
Humans do not need to attach all of those paths manually.

When something breaks, humans must be told to use **`G-fix.md`** (see `QUICKSTART.md` §5 and `.AI/docs/11-error-fix.md`).  
To see the live page, use **`H-preview.md`** (see `QUICKSTART.md` §9 and `.AI/docs/12-run-preview.md`). Never start duplicate servers.
